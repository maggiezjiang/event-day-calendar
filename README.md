# Event Day Calendar

Automatically updated calendar feeds for event days.

## 📅 Subscribe

Choose a calendar below and add its subscription link to your calendar app using **Subscribe from URL** or the equivalent option.

Your calendar app will periodically check for updates, so you do not need to download the `.ics` file manually.

### Available calendars

| Calendar | Description | Subscribe |
|---|---|---|
| **Wembley Events** | Events at Wembley Stadium | [Subscribe](https://raw.githubusercontent.com/maggiezjiang/event-day-calendar/main/calendars/wembley-events.ics) |

## 📁 Calendar files

Each calendar is available as an `.ics` file in the [`calendars/`](calendars/) directory.

The files are intended to be used as **calendar subscriptions**, rather than downloaded as static files.

The feeds are updated automatically when changes are detected in their event sources.
